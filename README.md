# Boleta Studio 0.6

Instalador de prueba para Android ARM64 (Android 6 o posterior).

**[Descargar Boleta Studio 0.6 para Android](https://github.com/patricksotomayor0111-star/boleta-studio-descargas/raw/refs/heads/main/Boleta-Studio-0.6.apk)**

[Descargar el instalador comprimido en ZIP](https://github.com/patricksotomayor0111-star/boleta-studio-descargas/raw/refs/heads/main/Boleta-Studio-0.6.zip)

## Instalar o actualizar

1. Abre el enlace del APK en Chrome desde tu celular y acepta la descarga.
2. En Chrome, abre **⋮ → Descargas** y toca `Boleta-Studio-0.6.apk`.
3. Si Android lo solicita, permite instalar aplicaciones desde Chrome y vuelve al instalador.
4. Pulsa **Actualizar** para conservar la aplicación y sus plantillas. Si aún no estaba instalada, pulsa **Instalar**.

Mantén instalada la versión anterior. Este APK conserva el identificador y la firma usados en las versiones de prueba anteriores. El ZIP es una alternativa de descarga: primero hay que extraer el APK que contiene.

## Edición desde la vista previa

- Toca un texto para editarlo con el teclado.
- Activa **Mover** y arrastra textos o líneas para colocarlos.
- Arrastra el punto azul derecho para ensanchar el cuadro de texto.
- Usa **+ Añadir → Texto editable** para agregar texto.
- Arrastra un elemento a la papelera para quitarlo; **Deshacer** recupera cambios.
- Guarda la plantilla para reutilizar su diseño.

La actualización se instala abriendo el APK descargado; los avisos automáticos dentro de la aplicación siguen pendientes.

## Validación

Versión `0.6.0`, código de versión `7`, paquete `com.boleta.editor`, arquitectura `arm64-v8a`. Compilación y firma verificadas; 70 pruebas automatizadas aprobadas. Falta la validación en un teléfono y una impresora físicos. Es una versión de prueba distribuida fuera de Google Play.

Este repositorio contiene únicamente el APK, el mismo instalador comprimido, esta guía y sus sumas SHA-256. Los archivos no contienen fotografías, sesiones de WhatsApp, claves ni datos guardados en el teléfono. Las sumas de verificación están en [SHA256SUMS.txt](SHA256SUMS.txt).
